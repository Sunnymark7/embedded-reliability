# 模块契约模板

仅填写本次相关内容；每个事实标来源，未知写明未知。此模板不要求创建额外实现层。

| 项目 | 约定 |
| --- | --- |
| 需求与可观察验收 | 待从本次任务记录 |
| 组件/profile、目标版本 | 待从构建与源码确认 |
| 负责/不负责的行为、依赖方向 | 待按实际模块确定 |
| 公共入口和状态转换 | init/start/stop/deinit 是否需要；重复/非法调用语义 |
| 输入输出 | 类型、范围、单位、长度/容量、NULL/空输入、别名/重叠限制 |
| 所有权 | 分配/借用/转移/释放；异步 buffer/context 有效期 |
| 执行上下文 | 可调用线程/ISR、是否可睡眠、重入、同步机制与锁顺序 |
| 完成和取消 | 提交失败、同步/异步完成、回调次数、取消后回调、最后引用 |
| 时间与资源 | 时钟域、总截止期、队列/栈/堆/速率上限及测量依据 |
| 错误与恢复 | 分类、部分结果、幂等性、重试总预算、降级/复位 |
| 外部布局 | 协议/UAPI 版本、字节序/单位、保留字段、兼容策略 |
| 硬件依据 | 手册修订/勘误/头文件/同树实现 |
| 验证 | 正常、边界、故障、并发、目标板；未具备条件 |

小函数直接在头文件注释里表达这些必要约束，不必逐项填表。
