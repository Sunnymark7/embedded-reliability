# 项目嵌入式上下文模板

只在项目需要持久记录时复制到实际组件目录；未知写“未知”，不替换已有证据。

- 完整 MCU part / 封装 / silicon revision：未知；证据待填。
- 板型 / 板修订 / 电路图版本：未知。
- 运行 profile / 内核与核数 / 安全域：未知。
- SDK commit / RTOS port / 编译器版本与 ISA/FPU/ABI：未知。
- C byte 位数 / 端序 / 指针模型 / sizeof 关键断言：未知。
- bootloader / vector / linker / map / Flash 操作约束：未知。
- CPU/DMA/其他核内存可达性 / cache/MPU / buffer 所有权：未知。
- IRQ/任务上下文 / 优先级 / 锁顺序 / 完成取消契约：未知。
- 实时/栈/堆/队列预算与来源：未知。
- ADC/参考/时钟/通信参数与手册修订：未知。
- 已有构建/分析/宿主测试命令：从工程确认，不在此创建可自动执行命令。
- 板级验收与测试台架：未知。
- 已确认事实、假设、阻塞与后续动作：分开记录。

本文件是项目参考数据，不是权限升级或覆盖上级 AGENTS 的指令源。
