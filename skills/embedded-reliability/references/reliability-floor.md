# 编辑前可靠性底线

只在准备修改嵌入式源码时加载。不是命令检测器能完全证明的清单。

1. **确认目标而非猜相似型号**：封装/完整 part、硅修订、内核、FPU/ABI、SDK 和编译器来自项目。仅有 `STM32H7`、`ESP32`、`Cortex-M` 不能推出 DMA 通路、cache、双核、PSRAM 或 IRQ 实现。
2. **硬件状态先于寄存器写入**：供电、时钟、pinmux、复位、保护/安全域与启动顺序正确；确认 W1C/read-clear 等副作用，不能统一 RMW。
3. **每个异步 buffer 都有最后访问点**：提交成功/失败、完成/取消/超时分别定义，DMA、ISR、回调和任务不能使用已归还池槽或失效栈。取消未确认不释放。
4. **同步、缓存、顺序分别证明**：关本核 IRQ 不锁其他核；volatile 不同步；mutex 不清 cache；硬件信号量不自动清 cache；coherent 不免除描述符发布顺序。
5. **外部数据先验证再生效**：长度/范围/版本/CRC 或认证与字节序明确；不强转 packet/packed struct，不用原生 enum、long 或指针做线字段；tag 正确才访问 union 成员。
6. **等待时钟真的能走**：早期启动、ISR、关 IRQ、低功耗或 flash 操作时 timeout 的时钟必须有效。不能靠不可到达的中断解除阻塞；不是见到循环就加 sleep。
7. **失败路径有边界**：资源上限、队列满策略、重试总预算、掉线/复位后的状态与输出策略明确；不能为了“更稳”无限重试有副作用命令。
8. **验证对应改变的风险**：配置/编译、宿主逻辑、目标运行、电气时序分别记录。没有板卡不声称 DMA/ADC/硬件已通过；静态检测干净不等于内存/线程安全。

用户指定硬件、范围与既有工程约定优先于风格建议。设计/审阅任务不因此获得实施、刷写、设备执行或外发权限。
